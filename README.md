# Food Delivery App

A simple food delivery web application built with Flask, similar to Uber Eats or Swiggy.

## Features

- User registration and login
- Restaurant management (for restaurant owners)
- Menu browsing and cart functionality
- Order placement and tracking
- Basic delivery address handling

## Setup

1. Install dependencies:
   ```
   pip install -r requirements.txt
   ```

2. Run the application:
   ```
   python app.py
   ```

3. Open your browser and go to `http://localhost:5000`

## Usage

- Register as a customer or restaurant owner
- Restaurant owners can add restaurants and menu items
- Customers can browse restaurants, add items to cart, and place orders
- View order history and details

## Database

The app uses SQLite database (`food_delivery.db`) which is created automatically on first run.
